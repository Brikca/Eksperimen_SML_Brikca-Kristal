# Eksperimen_SML_Brikca-Kristal

Proyek eksperimen Machine Learning menggunakan dataset Telco Customer Churn.

## Struktur Repository

- telco_raw : dataset mentah
- preprocessing : notebook eksperimen, script otomatisasi, dan dataset hasil preprocessing
- .github/workflows : GitHub Actions untuk menjalankan preprocessing otomatis

## Dataset

Telco Customer Churn Dataset

## Workflow

Setiap perubahan pada repository akan menjalankan proses preprocessing secara otomatis menggunakan GitHub Actions.
